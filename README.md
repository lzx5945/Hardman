# Hardman
中国高校智能机器人创意赛主题三—轮式格斗机器人A类
一、总体设计理念
1.1 活动铲构型
采用 活动铲 替代传统固定铲，铲子可在出发时扬起，上台时利用惯性自然下落贴地。

该设计为内部部件（电机、电池、传感器等）释放出更大布置空间，同时保持整车尺寸为 27×29 cm，严格符合 A 类规则（≤30×30 cm）。

1.2 关节摩擦控制
铲臂转动处使用 轴承 + 自锁螺母 组合，精确调控摩擦力：

足够摩擦 → 铲子下落平稳不卡顿；

避免过紧 → 保证铲子能自由旋转，随地形自然贴合。

二、主体结构与材料策略
2.1 分层布局
层级	材料	作用
底盘	3mm 3K 碳纤维板	高刚性、低重心，提升行驶稳定性
上层顶板	玻璃纤维（等效铝材）	轻量化，同时保持足够刚度
非承力支架 & 上层建筑	3D 打印塑料	复杂结构易成型、成本低，显著控制整车质量
2.2 空间与传感器布置
活动铲释放更多内部空间，本车相较往届 预留更多传感器安装位。

通过固定结构的巧妙配合，将传感器精确布置于最佳位置，并可调整安装角度，使各传感器发挥最大感知效能——这是本设计的结构创新点之一。

三、关键细节与创新机构
3.1 轮毂设计
内凹外平 造型：内凹部分环绕保护联轴器，抵御侧向撞击；

配合 抱紧式联轴器，防止轮子径向与轴向滑脱；

轮齿采用 T 字型牙状花纹，浇筑后与胶皮形成强力咬合，保证轮体一体化。

<img width="545" height="427" alt="image" src="https://github.com/user-attachments/assets/298d82ca-3ed5-4b16-bf8e-99460d367c36" />

3.2 双模浇筑胎皮系统
通过 两次分步浇筑，实现胎皮 内硬外软 的密度梯度：

内圈硬 → 保证轮子支撑性；

外圈软 → 增大触地面积，显著提升摩擦力。

该工艺兼顾了高速转向稳定性和爆发加速抓地力，为对抗提供可靠行走基础。

缺点；
传感器选型不是最优解 12V光电传感器的加入导致电路更加复杂 交错的电路板给结构空间的利用提出很大考验 同时重量大大提高 导致没能达成头重脚轻的效果 对抗时颇显吃力
读者改进时可以全部选用5v传感器 同时前铲适当改变形状并使用光固化材料或者金属
